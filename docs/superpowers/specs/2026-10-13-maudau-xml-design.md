# Специфікація системи генерації XML-прайсів для маркетплейсу MAUDAU

## 1. Мета та огляд
Створення високопродуктивного, модульного генератора XML/YML фідів для маркетплейсу **MAUDAU** на базі платформи Python.
Початковий постачальник: **yavshoke** (`https://crm.yavshoke.ua/media/export/all_drop_opt_price.xml`).
Цільовий репозиторій: `https://github.com/lozko1991-blip/MAUDAU`.

## 2. Стандарти та вимоги MAUDAU
* **Формат:** XML/YML, кодування суворо `UTF-8` без BOM.
* **Коренева структура:**
  ```xml
  <?xml version="1.0" encoding="UTF-8"?>
  <yml_catalog date="YYYY-MM-DD hh:mm">
      <shop>
          <currencies>
              <currency id="UAH" rate="1"/>
          </currencies>
          <categories>
              <category id="[ID_постачальника]" portal_id="[ID_MAUDAU]">[Назва_категорії_UA]</category>
          </categories>
          <offers>
              ...
          </offers>
      </shop>
  </yml_catalog>
  ```
* **Категорії (`<category>`):**
  * `id`: унікальний ідентифікатор у нашій системі / системі постачальника.
  * `portal_id`: офіційний ID кінцевої категорії з довідника MAUDAU (файл `Всі категорії MAUDAU (3).xlsx`). Забезпечує автоматичний 100% мапінг під час імпорту.
  * Назва категорії: 100% українська мова, до 255 символів, без HTML.
* **Товарні пропозиції (`<offer>`):**
  * `id`: унікальний ідентифікатор (формат `yav_XXXXXXX`, лише символи `Aa-Zz`, `0-9`, без пробілів і кирилиці).
  * `available`: суворо `"true"` або `"false"`.
  * `<price>`: розрахункова роздрібна ціна у гривнях (десятковий роздільник — крапка).
  * `<price_old>`: рекомендована закреслена ціна (наприклад, +25% від роздрібної).
  * `<categoryId>`: прив'язка до `id` категорії.
  * `<picture>`: від 1 до 12 фотографій (без кирилиці та пробілів у посиланнях, перша — головна).
  * `<name_ua>`: обов'язкова назва українською (до 255 символів, суворо без HTML-тегів).
  * `<name_ru>`: назва російською (до 255 символів, без HTML-тегів).
  * `<description_ua>`: обов'язковий опис українською (до 10 000 символів, у `<![CDATA[...]]>`).
  * `<description_ru>`: опис російською (до 10 000 символів, у `<![CDATA[...]]>`).
  * `<param name="...">`:
    * Назва та значення непорожні, українською мовою.
    * Без HTML-тегів, дедуплікація імен.
    * **Залізне правило MAUDAU:** Мінімум 3 характеристики на товар для публікації.
  * `<vendor>`: назва бренду / виробника (якщо відома).
  * `<country>`: країна-виробник українською.

## 3. Фільтрація та Ціноутворення
1. **Фільтр виключення категорій (Чорний список):**
   * Ролети: `40863` (*Ролети*), `42166` (*Ролети закритого типу*), `42165` (*Ролети відкритого типу*), а також за ключовими словами `ролет`, `рулонн`.
   * Тарілки: `15041` (*Тарелки и пиалы*), `15055` (*Детские тарелки и пиалы*), а також за ключовими словами `тарілк`, `тарелк`.
2. **Формула націнки для yavshoke:**
   $$\text{Final Price} = \text{round}(\text{Purchase Price} \times 1.30 + 50)$$
3. **Фільтр мінімальної фінальної ціни:**
   $$\text{Final Price} \ge 300\text{ грн}$$
   (Товари з розрахунковою ціною на MAUDAU нижче 300 грн не потрапляють у фід).

## 4. Архітектура нормалізації характеристик
1. **База значень MAUDAU (`maudau_val_ru_to_uk.json`):**
   * 11 844 офіційних канонічних перекладів значень MAUDAU, витягнутих з `merchant_categories_*.xml`.
2. **Словник атрибутів MAUDAU (`param_name_mapping.json`):**
   * 129 уніфікованих назв параметрів MAUDAU (`Колір`, `Матеріал`, `Діаметр`, `Об'єм`, `Спальний розмір` тощо).
3. **Гарантія $\ge 3$ параметрів:**
   * Автоматичне додавання обов'язкових інваріантів (`Стан: Новий`, `Бренд`, `Країна-виробник`), якщо у товару не вистачає параметрів для проходження модерації.

## 5. Файлова структура проекту
* `maudau_xml_generator.py` — основний генератор XML.
* `category_mapper.py` — логіка зіставлення категорій та проставляння `portal_id`.
* `param_normalizer.py` — логіка перекладу та стандартизації характеристик під MAUDAU.
* `markup_config.py` — правила націнок, пороги та фільтри виключень.
* `category_mapping.json` — словник зв'язки категорій постачальника з MAUDAU `portal_id`.
* `maudau_dict.json` — скомпільований довідник атрибутів та значень MAUDAU (11 844 значень).
* `tests/test_maudau_generator.py` — автоматичні тести ціноутворення, фільтрації та XML валідації.
* `FEED_PASSPORT_MAUDAU.md` — технічний паспорт фіду MAUDAU.
