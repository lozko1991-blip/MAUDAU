# План реалізації генератора XML-прайсів для MAUDAU

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Створити модульний генератор XML-фіду під стандарти MAUDAU для постачальника yavshoke з націнкою 30% + 50 грн, фільтрацією ролетів/тарілок/товарів < 300 грн, авто-мапінгом категорій (`portal_id`) та підгонкою характеристик під офіційну базу MAUDAU (11 844 значення).

**Architecture:** Модульна архітектура на Python з потоковим парсингом/генерацією (lxml.etree), окремими модулями нормалізації параметрів (`param_normalizer.py`), мапінгу категорій (`category_mapper.py`), конфігурації націнок (`markup_config.py`) та головним генератором (`maudau_xml_generator.py`).

**Tech Stack:** Python 3.10+, lxml, requests, openpyxl, pytest, git.

## Global Constraints
- XML UTF-8 без BOM, кореневий тег `<yml_catalog date="YYYY-MM-DD hh:mm">`
- Націнка Yavshoke: `round(price_raw * 1.30 + 50)`
- Фільтр: тільки товари з кінцевою ціною $\ge 300$ грн
- Суворе виключення категорій: ролети (`40863`, `42166`, `42165`), тарілки (`15041`, `15055`) та ключові слова
- Назви товарів: суворо без HTML, українською та російською
- Описи: до 10 000 символів, у CDATA
- Характеристики: українською мовою, без HTML, мінімум 3 параметри на товар
- Репозиторій: `https://github.com/lozko1991-blip/MAUDAU`
