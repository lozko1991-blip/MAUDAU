# MAUDAU — Мульти-постачальницький агрегатор XML-прайсів для маркетплейсу MAUDAU

Автоматизована високопродуктивна система підготовки, валідації та публікації об'єднаного товарного XML/YML каталогу для маркетплейсу **MAUDAU** ([merchant.maudau.com.ua](https://merchant.maudau.com.ua/)).

Система потоково обробляє каталоги **4 постачальників**, застосовує індивідуальні правила націнки, фільтрує товари за наявністю (`available == true`) та рентабельністю, видаляє дочірні категорії з менш ніж 3 товарами, очищає описи від телефонів/реклами, нормалізує характеристики під офіційну базу MAUDAU та генерує валідні XML і GZIP фіди з автопублікацією на GitHub Pages.

## 📌 Ключові бізнес-правила та постачальники

| Постачальник | Префікс | Націнка | Поріг ціни MAUDAU | Особливості |
|---|---|---|---|---|
| **Yavshoke** | `321_` | **+30% + 50 грн** | **$\ge 300$ грн** | Виключені ролети (40863, 42166, 42165) та тарілки (15041, 15055) |
| **Opt-Drop** | `1000_` | **+35% + 50 грн** | **$\ge 350$ грн** | Очищення ентитіс `&lt;p&gt;`, видалення inline-стилів |
| **Dropt** | `2010_` | **+20% + 50 грн** | **$\ge 350$ грн** | Фільтрація офферів без категорій |
| **Aveon** | `3001_` | **+15% + 50 грн** | **$\ge 350$ грн** | Потоковий chunked reader, форматування абзаців `\n\n` |

### Формула ціноутворення:
$$\text{Ціна продажу} = \operatorname{round}(\text{Ціна постачальника} \times (1 + \text{markup}) + 50)$$
$$\text{Стара ціна} = \operatorname{round}(\text{Ціна продажу} \times 1.25)$$

## ⚡ Оптимізація розміру фіду та чистота даних

1. **Тільки товари в наявності:** Повністю виключені товари з `available="false"` (відсіює понад 13 800 позицій).
2. **Фільтр категорій $\ge 3$ товарів:** Дочірні (кінцеві) категорії, що містять менше 3 товарів, автоматично видаляються разом із товарами.
3. **Глибоке очищення описів (`clean_description_html`):**
   - Видалення телефонів (+380, 0xx...).
   - Видалення контактів месенджерів (Viber, Telegram, WhatsApp, Instagram тощо) та рекламних закликів.
   - Видалення зовнішніх посилань та доменних імен.
   - Видалення вбудованих зображень `<img>`, скриптів, стилів.
   - Охайне форматування у семантичні абзаци `<p>...</p>`, списки `<ul><li>`, `<br/>`.
   - Захист CDATA (`]]>` $\to$ `]]&gt;`).
4. **Характеристики MAUDAU:**
   - Гарантовано $\ge 3$ параметри на кожен товар.
   - Авто-підгонка назв та значень під базу 11 844 характеристик MAUDAU.
5. **Мапінг категорій:**
   - Понад 2 540 категорій у `category_mapping.json` (понад 510 з прямим `portal_id`).

## 🚀 Структура проєкту

| Файл / Каталог | Призначення |
|---|---|
| `maudau_xml_generator.py` | Головний потоковий багатопотоковий генератор об'єднаного XML та GZIP фіду |
| `markup_config.py` | Конфігурація націнок, префіксів та порогів для всіх 4 постачальників |
| `category_mapper.py` | Модуль мапінгу категорій та формування тегів `<category portal_id="...">` |
| `category_mapping.json` | Словник відповідностей категорій постачальників $\to$ MAUDAU `portal_id` |
| `param_normalizer.py` | Нормалізатор характеристик з гарантією $\ge 3$ параметрів та авто-перекладом |
| `maudau_dict.json` | Скомпільована база офіційних назв та значень характеристик MAUDAU |
| `FEED_PASSPORT_MAUDAU.md` | Офіційний технічний паспорт стандарту даних MAUDAU |
| `tests/test_maudau_feed.py` | Набір з 20 автоматичних юніт-тестів валідації фіду |
| `.github/workflows/maudau.yml` | CI/CD пайплайн з генерацією, валідацією та деплоєм на GitHub Pages |
