# MAUDAU — Генератор XML-прайсів для маркетплейсу MAUDAU

Автоматизована система підготовки та публікації товарного XML/YML каталогу для маркетплейсу **MAUDAU** ([merchant.maudau.com.ua](https://merchant.maudau.com.ua/)).

Система завантажує каталог постачальника (перший постачальник — **Yavshoke**), застосовує правила ціноутворення, фільтрує нерентабельні або заборонені категорії, автоматично мапить категорії на дерево MAUDAU за допомогою `portal_id`, нормалізує характеристики під офіційну базу MAUDAU та генерує валідний фід для імпорту.

---

## 📌 Ключові бізнес-правила та налаштування

### 1. Постачальники
* **Yavshoke:** `https://crm.yavshoke.ua/media/export/all_drop_opt_price.xml` (префікс `321_`).
* Архітектура розроблена з урахуванням легкого підключення нових постачальників у майбутньому.

### 2. Ціноутворення та фільтр рентабельності
* **Формула націнки:** `Ціна MAUDAU = round(Ціна постачальника * 1.30 + 50)` (+30% та +50 грн).
* **Маркетингова стара ціна (`<price_old>`):** `round(Ціна MAUDAU * 1.25)` (+25% закреслена ціна).
* **Фільтр мінімальної ціни:** Публікуються виключно товари з фінальною ціною продажу на MAUDAU **$\ge 300$ грн** (вхідна закупівля приблизно від 193 грн). Товари з ціною нижче 300 грн автоматично відсікаються.

### 3. Заборонені категорії (Фільтр виключень)
З каталогу Yavshoke повністю виключені наступні групи:
* **Ролети / рулонні штори:** ID `40863`, `42166`, `42165` та стоп-слова `ролет`, `рулонн` (понад 20 500 товарів).
* **Тарілки:** ID `15041`, `15055` та стоп-слова `тарілк`, `тарелк` (понад 1 350 товарів).

### 4. Мапінг категорій (Гібридний підхід)
* Категорії з файлу `category_mapping.json` автоматично отримують офіційний `portal_id` маркетплейсу MAUDAU (з реєстру `Всі категорії MAUDAU (3).xlsx`).
* Формат вивантаження: `<category id="321_123" portal_id="271" parentId="...">Назва UA</category>`.
* Для категорій без прямого `portal_id` вивантажується стандартизована українська назва, що дозволяє підтвердити прив'язку в 1 клік у кабінеті мерчанта.
* У фінальний фід потрапляють лише категорії з реально активними товарами.

### 5. Нормалізація характеристик (MAUDAU Attributes)
* **Вимога MAUDAU:** Кожен товар зобов'язаний містити **щонайменше 3 характеристики** для успішного проходження модерації.
* **База MAUDAU:** Використовується скомпільований словник `maudau_dict.json` (129 офіційних назв атрибутів та 11 844 стандартизованих значень).
* Російські параметри автоматично перекладаються українською та приводяться до канонічного вигляду MAUDAU.
* За нестачі параметрів у вихідному фіді генератор автоматично гарантує наявність параметрів `Стан: Новий`, `Бренд`, `Країна-виробник`, `Гарантія: 14 днів`.

## 🚀 Структура проєкту

| Файл / Каталог | Призначення |
|---|---|
| `maudau_xml_generator.py` | Головний потоковий генератор фіду (обробка великих XML без переповнення пам'яті) |
| `markup_config.py` | Модуль розрахунку націнки (+30% +50 грн), фільтра від 300 грн та списку виключень |
| `category_mapper.py` | Модуль прив'язки категорій та формування тегів `<category portal_id="...">` |
| `category_mapping.json` | Словник мапінгу категорій Yavshoke $\to$ MAUDAU `portal_id` |
| `param_normalizer.py` | Нормалізатор характеристик з гарантією $\ge 3$ параметрів та авто-перекладом |
| `maudau_dict.json` | Скомпільована база значень та назв характеристик MAUDAU |
| `FEED_PASSPORT_MAUDAU.md` | Офіційний технічний паспорт стандарту даних MAUDAU |
| `tests/` | Набір юніт-тестів та інтеграційний валідатор фіду |
| `.github/workflows/maudau.yml` | CI/CD пайплайн для щоденного оновлення фіду через GitHub Actions |

## 🛠️ Запуск локально

### Встановлення залежностей
```bash
pip install lxml requests
```

### Запуск тестів
```bash
python -m unittest discover tests
```

### Генерація XML фіду
```bash
python maudau_xml_generator.py
```
Результат буде збережено у файл `maudau_feed.xml`.
